# 编辑器 AI 对话

## 联网搜索与来源

原位、侧栏、浮动和全屏输入区的底部均直接显示「联网搜索」复选框，可选择下一轮是否允许联网搜索，无需打开「＋」菜单。各入口共享勾选状态。开启仅表示允许模型按需调用，不能绕过 Agent 工作区的启停与 writing 任务授权；关闭会在服务端移除 webSearch，不是仅增加一句提示词。

搜索执行完成后，SSE 工具事件包含结构化 sources，不依赖模型在正文是否引用。回答下方显示来源编号、标题、站点、可用发布日期和安全外链。一次生成中多次搜索使用连续 S1、S2 等索引，避免不同来源同名。思考、工具状态、来源和候选正文始终分离，插入正文不会自动夹带检索过程。

同一回复的全部检索来源合计默认只展示前三条，超过三条时显示剩余数量和展开按钮，可再次收起。展开后的列表最高 320px，超出时内部滚动；长标题最多显示两行。

## 图片理解

当前已核实并开放 DeepSeek 官方 deepseek-flash，兼容仍由 Flash 承接的 deepseek-v4-flash-vision-exp 名称。编辑器通过 capabilities 接口读取当前绑定，不静默替换模型，也不把所有文本模型都声称为视觉模型。

空格唤起的原位输入框与对话面板都可通过右侧回形针按钮直接选择 JPEG、PNG、GIF 或 WebP，原位上传无需先打开侧栏。各入口共享附件预览和移除操作，支持只发送图片；读取失败或格式不符会在当前输入区提示。每条消息最多 3 张，每张最多 2 MiB，当前及历史图片总预算 6 MiB，单边最大 8192 像素。后端检查真实类型、尺寸、编码及总预算，不只相信 MIME 或扩展名。不支持 SVG、任意远程图片 URL 或客户端提供的第三方 file_id。

原位空态为约 52px 的单行入口，输入内容或添加附件后自动展开。联网搜索采用图标胶囊复选控件，点击切换，支持键盘聚焦与空格勾选。正在工作、思考和生成时显示渐变流动文字及旋转图标，结束或停止后移除动画；遵循系统「减少动态效果」设置。

原位入口在点击编辑器其他区域或通过键盘移出焦点时自动收起；打开侧栏时左侧原位入口和选区操作同时隐藏，未发送的输入继续保留在侧栏中。隐藏预览后，宽屏源码正文和顶部 Markdown 工具栏最多 840px，并在剩余工作区居中；侧栏宽度变化时两者保持对齐。恢复预览时继续使用可拖动的分栏布局。

这版采用 Rig 原生 UserContent::image_base64，向 DeepSeek 对话接口发送标准 image_url 内容块。图片保留在用户历史中，支持连续追问及多轮工具调用；没有把图片当成文字路径交给模型。发送失败会把本轮附件放回输入区，停止或失败的回答不会进入下一轮有效历史。

图片仅在浏览器当前对话内存中存在，不进入公开素材库，不写文章草稿恢复缓存，也不保存在第三方 Files 存储中；请求会将图片交给当前绑定的模型提供商。关闭面板保留本次内存对话，新建对话清空附件及上下文，刷新不恢复 AI 对话。

DeepSeek 的 Files API 是另外一种上传后以 file_id 复用图片的协议，适合更大图片与跨请求复用。当前不是 Files API 实现，不提供远程文件管理，也不声称 Rig 的通用 OpenAI File 内容块自动等同于 DeepSeek 的 file_id 格式。此次使用官方同样支持的 Base64 方式以避免增加远程存储、文件生命周期和公开链接。

## 接口

- GET /api/v1/admin/agent/writing/capabilities：搜索权限、视觉能力与当前模型名，不包含密钥。
- 写作普通响应及 SSE 输入增加 web_search 和 images，用户 history 可附 images，助手历史不允许图片。
- 普通与流式接口均限制 10 MiB 请求体；旧客户端缺省保持按需搜索行为。
