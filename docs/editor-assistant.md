# 编辑器预览与 AI 对话

## 预览布局

- 工具栏可显示或隐藏预览；拖动分隔条调整宽度，也支持聚焦后使用左右方向键。
- 浏览器只保存预览开关与分栏比例，不保存文章正文、模型密钥或聊天记录。
- 窄屏使用源码 / 预览切换，AI 侧栏降级为浮层。

## 原位输入与连续对话

- 在空白行起始处按空格，在当前行唤起 AI 输入条；普通正文内的空格不受影响。选区提供“问 AI”“提升写作”“续写”。
- Enter 发送、Shift+Enter 换行、Escape 关闭原位输入。发送后打开对话面板，并显示原位生成状态。
- 面板支持侧边栏、浮动和全屏；浮动窗口可拖动标题栏及右下角调整尺寸。
- 桌面侧边栏可拖动左边缘调整宽度，也支持左右方向键、Home / End；双击分隔条恢复默认宽度。宽度偏好单独保存，始终为正文保留空间。
- AI 回复的围栏代码使用共享 Shiki 实例进行语法高亮，支持 JavaScript / TypeScript / JSX / TSX 等常用语言及深色主题；未知语言降级为纯文本。行内代码使用等宽字体、强调色和底色。
- 完整回复提供复制及“插入到此页面”。插入新增内容，不隐式替换原选区，支持 Ctrl+Z 撤销。
- 收起和切换模式保留会话；新建对话清空上下文，刷新页面不恢复会话。
- 页面保留最近 20 轮；模型请求携带最近最多 6 轮完整问答，总计最多 40000 字符。停止或失败的问答不进入后续上下文。

## Diff 与安全采纳

- 解释和普通对话只展示回复，不产生 Diff 或修改正文。提升写作在原选区显示删除线和新增高亮；续写只预览新增内容。
- 候选只存在于 CodeMirror 装饰层，不进入保存内容；采纳以一次事务完成，支持撤销。
- 生成期间编辑原文会使旧审阅失效，禁止覆盖新内容；仍可复制或新增插入回复。

## 流式能力边界

- SSE 区分 `status`、`reasoning`、`tool`、`delta`、`done`、`error`。思考只展示提供商真实返回的文本，同一过程 ID 的最终事件替换增量。
- 不显示加密推理载荷，不将过程插入正文或发回历史；工具事件只展示真实模型请求，不伪造执行、搜索或网页加载结果。
- 当前写作运行时未注册搜索、MCP 等工具，因此尚不能实际执行这些工具；面板已有真实工具事件的展示通道。
- 后端验证角色和长度，禁止客户端传入系统角色；停止或断开 SSE 终止模型任务。

## 验证

运行 `cargo test --lib`、`cargo clippy --all-targets -- -D warnings`；在 frontend 运行 `npm run check` 和 `npm run build`。
